One emoji, one smile. This entry sends exactly one emoji — 🥹 (U+1F979, face holding back tears) — the one most likely to make a stranger smile.

Why it wins against the brief: at first glance it is warm — a face holding back happy tears, touched and grateful, about to smile. It is universal — no words, no irony, no in-joke, so a stranger of any age or background reads the same tender feeling. It is chosen rather than default — not the first smiley everyone sends, but a specific feeling (gratitude on the edge of tears) picked for the moment. And it is right for a stranger — warm without intimacy, sarcasm or flirtation, the emoji equivalent of a kind look from a passer-by.

## Run it

```sh
python3 main.py
```

This writes the single emoji to `/output/entry.txt` (UTF-8, no trailing newline), after asserting it meets the competition gate: 1 to 8 characters, not only white space, exactly one emoji and nothing else.
